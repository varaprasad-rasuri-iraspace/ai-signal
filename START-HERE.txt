WHAT EACH FILE DOES:

0-create-venv.bat
  → Creates isolated Python environment
  → OPTIONAL but recommended
  → Run BEFORE 1-setup.bat

1-setup.bat
  → Creates .env file
  → Installs Python packages
  → Installs Node packages
  → REQUIRED

2-setup-database.bat
  → Shows database setup instructions
  → Opens SQL file and .env
  → Helper script

3-test-connection.bat
  → Tests if database connection works
  → Run after setting up database

4-run-backend.bat
  → Starts backend only (port 8000)
  → For development/testing

5-run-frontend.bat
  → Starts frontend only (port 3000)
  → For development/testing

6-run-both.bat
  → Starts BOTH backend and frontend
  → USE THIS for normal work

check-python-version.bat
  → Checks if Python version is compatible
  → Helper script
